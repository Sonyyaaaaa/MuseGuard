# MuseGuard: вимоги до проєкту

## Ідея

MuseGuard допомагає працівнику музею стежити за вітриною з експонатом. Система має окремо показувати присутність людини поруч, зміну освітлення та механічний вплив на корпус. Ці спостереження можуть потребувати перевірки, але самі по собі не встановлюють намір людини чи факт крадіжки.

Робота індивідуальна. Перший прототип працюватиме без фізичної плати, у Wokwi на STM32 HAL. Для ЛР1 потрібні відтворювана збірка, запуск із UART і LED та підготовлені вимоги. Сенсори, їхні драйвери й одночасна робота належать до ЛР2.

## Функціональні вимоги

- **FR-01.** Після запуску система повинна повідомити через UART модель і поточний стан та періодично підтверджувати, що головний цикл працює.
- **FR-02.** Система повинна реєструвати присутність людини біля вітрини окремим типом події, без позначки про крадіжку.
- **FR-03.** Система повинна реєструвати зміну освітленості відносно базового рівня, коли зміна перевищує перевірений поріг.
- **FR-04.** Система повинна реєструвати короткий удар по корпусу окремо від тривалої зміни його положення.
- **FR-05.** Система повинна реєструвати зміну нахилу корпусу. Чи можна виявити повільне переміщення без зміни нахилу, потрібно перевірити; поки це не заявлена можливість.
- **FR-06.** Кожне повідомлення про подію повинно містити її тип і час від запуску пристрою.
- **FR-07.** Система повинна обробляти сигнали всіх трьох сенсорів у межах одного циклу роботи, не підміняючи один тип події іншим.
- **FR-08.** Система повинна відрізняти інформаційне повідомлення про присутність від тривоги за механічним впливом на корпус. Правила для зміни світла визначаються після перевірки показів.
- **FR-09.** Після перезапуску система повинна знову перейти в задокументований початковий стан і повідомити про нього через UART.

Пороги, інтервали опитування та час реакції встановлюємо за результатами вимірювань у Wokwi. Цей документ поки не стверджує, що вимоги реалізовані.

## Компоненти

| Запланована модель | Інтерфейс | Для яких вимог | Розглянута альтернатива |
| --- | --- | --- | --- |
| PIR Motion Sensor у Wokwi | GPIO | FR-02, FR-07 | Кнопка дає керований цифровий сигнал, але не відтворює присутність людини. |
| Photoresistor Sensor у Wokwi | ADC | FR-03, FR-07 | Потенціометр зручний для перевірки ADC, але не відповідає сцені освітлення вітрини. |
| MPU-6050 у Wokwi | I²C | FR-04, FR-05, FR-07 | Кнопка або датчик нахилу не дають окремих даних для удару й зміни орієнтації. |

Точні піни, живлення, адреси, діапазони вимірювань і відповідність моделей Wokwi фізичним модулям слід звірити в `docs/hardware-components.md` перед підключенням. Вибір STM32C031C6 зі стартового шаблону ще потребує погодження з викладачем.
